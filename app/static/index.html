              📌 Project Overview & Novelty

              ShieldGuard AI is a hybrid cyber threat intelligence platform engineered to combat the rising tide of multi-vector social engineering attacks. Unlike traditional monolithic spam filters that only check email, ShieldGuard correlates telecom caller spoofing, lookalike homoglyphs, deceptive subdomains, QR quishing payloads, and psychological urgency triggers simultaneously.

              ⚙️ System Architecture Pipeline

              Client UI (ES6 / HTML5) ➔ FastAPI Gateway ➔ Multi-Vector Heuristic & ML Engines ➔ Local Threat Watchlist (SQLite) ➔ Optional Cloud Threat Feeds

              🧠 Core Algorithmic Contributions

              • Levenshtein Edit Distance: Identifies 1-character typosquatting variations against top financial and tech brands.
              • Homoglyph Normalization Matrix: Maps visual character lookalikes (e.g. Cyrillic/digits '0'➔'o', '1'➔'l') to unmask spoofed domains.
              • E.164 Telecom Classification: Integrates Google libphonenumber metadata to flag unallocated, VoIP spoofed, and Wangiri toll trap codes.
              • Subdomain Deception Heuristic: Distinguishes legitimate apex domains from deceptive subdomain embedding (e.g. paypal.com.fake.xyz).
              • NLP Urgency & Coercion Regex Engine: Detects synthetic emergency panic prompts (e.g., account suspension, arrest warrants, lottery traps).
